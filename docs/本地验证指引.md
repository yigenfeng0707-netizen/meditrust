## 一、后端全量回归

```bash
cd oumed-chain/backend
python3 -m venv .venv
.venv/bin/python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple \
  pytest pytest-cov pytest-asyncio \
  fastapi sqlalchemy pydantic pydantic-settings python-dotenv httpx \
  aiosqlite numpy scikit-learn pandas cryptography greenlet alembic \
  python-multipart Pillow redis pypdf chromadb openai python-alipay-sdk

DEMO_OFFLINE=true .venv/bin/python -m pytest -q
```

关键说明：

- `DEMO_OFFLINE=true` 会跳过 LLM / 知识库初始化。未设置时，TestClient 触发 lifespan 会尝试初始化外部模型服务，本机可能长时间阻塞。
- `pytest.ini` 的覆盖率门槛为 63%。

## 二、前端生产构建

```bash
cd oumed-chain/frontend
env -u NODE_OPTIONS NEXT_DISABLE_STANDALONE=1 NEXT_TELEMETRY_DISABLED=1 \
  ./node_modules/.bin/next build
```

关键说明：

- `env -u NODE_OPTIONS` 移除 WorkBuddy 沙箱注入的 Node 语言 shim；该 shim 会导致 webpack 缓存读写经 broker 转发时失败。
- `NEXT_DISABLE_STANDALONE=1` 使用独立构建目录 `.next-build`，避免覆盖开发预览产物。

本次结果：21 个页面全部静态生成，构建成功；仅有 `@next/next/no-img-element` 非阻断警告。
